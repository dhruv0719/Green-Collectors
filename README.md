# Green-Collectors

## What is Green Collectors?
```
A gamified sustainability tracking app where users log eco-friendly actions (tree planting, clean-ups, recycling, low-carbon transport), see their personal carbon footprint broken down by category (transport, food, home energy, shopping, flights), earn green points and badges, compete on a leaderboard, and can buy or propose eco-friendly products in an in-app marketplace — with an AI chatbot ("Green Guide") giving personalized sustainability advice.
```
---
## Why are you building it?
```
I wanted to build something with a real data/logic layer (CO2 calculation) instead of another CRUD todo app.
```
---
## Who will use it?
```
Individual users who want to track and reduce their personal carbon footprint — casual eco-conscious consumers, not enterprises. The mockup implies India-based users (₹ pricing, India benchmark stats)
```
---
## What problem does it solve?
```
Green Collectors makes sustainable living measurable, engaging, and actionable.
```
